# Application Execution Screenshots & Interface Guide

This directory contains visual reference descriptions and screenshot placeholders for the **Java Log Analyzer & Monitoring System**.

---

## 1. Web Dashboard Interface (`http://localhost:8080/`)

- **Top Bar**: System status pill (`System Live`), Supabase DB sync button, View Report button.
- **Metrics Cards Grid**: Total Logs (`42`), INFO (`18`), WARNING (`16`), ERROR (`8`), Skipped Lines (`2`).
- **Security & System Alerts Section**: Active alert cards showing High Error Count, Failed Login Security Alert, Repeated Error Pattern, and Excessive Warning Alert.
- **Log Explorer Data Table**: Table with filter pills (`ALL`, `INFO`, `WARNING`, `ERROR`), search input, and date picker.

---

## 2. Interactive Terminal CLI Interface

- Menu options 1 through 10 demonstrating log loading, summary viewing, level filtering, keyword search, date filtering, alert pattern detection, report export, Web server launch, and Supabase database synchronization.
